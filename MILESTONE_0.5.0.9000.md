# eyeprocess 0.5.0.9000 research-scale programme

This milestone adds deterministic validation orchestration, hardened
advanced process models, independent vendor-evidence infrastructure,
stable API/storage contracts, explicit optional-engine adapters, and a
synthetic multimodal reproduction benchmark.

The software implementation is not itself evidence of model validity or
vendor compatibility. Dynamic hidden-state, functional-pupil,
strategy-mixture, and gaze-diffusion families remain experimental until
their declared promotion gates pass using executed simulations,
sensitivity studies, independent exports, engine comparisons, and
empirical reproductions.
