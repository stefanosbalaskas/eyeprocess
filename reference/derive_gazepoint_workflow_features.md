# Derive the complete Gazepoint workflow feature set

Derive the complete Gazepoint workflow feature set

## Usage

``` r
derive_gazepoint_workflow_features(x, reset_workflow_features = TRUE)
```

## Arguments

- x:

  An \`eye_dataset\` with reconstructed media trials.

- reset_workflow_features:

  Remove features previously generated by this workflow while preserving
  native Gazepoint Data Summary features.

## Value

The updated \`eye_dataset\`.
