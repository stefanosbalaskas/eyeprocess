# Predict a latent trait at arbitrary times

Predict a latent trait at arbitrary times

## Usage

``` r
predict_theta_at_time(object, time)
```

## Arguments

- object:

  A fitted eyeprocess model or audit object.

- time:

  Time values.

## Value

An R object containing a latent trait at arbitrary times. The concrete
class and structure follow the selected method, engine, or input object
and are preserved as documented by that workflow.
