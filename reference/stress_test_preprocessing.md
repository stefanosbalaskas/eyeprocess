# Stress test preprocessing

Stress test preprocessing

## Usage

``` r
stress_test_preprocessing(
  runner,
  variants,
  replications = 25L,
  seed = 20260808L
)
```

## Arguments

- runner:

  Function that executes one stress-test scenario.

- variants:

  Preprocessing variants to evaluate.

- replications:

  Number of simulation or validation replications.

- seed:

  Random-number seed.
