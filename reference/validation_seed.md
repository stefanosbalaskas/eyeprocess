# Allocate a deterministic validation seed

Part of the research-scale validation, advanced-model, interoperability,
storage, adapter, or reproducibility programme. Experimental model
functions remain subject to declared evidence gates.

## Usage

``` r
validation_seed(design, replication, base_seed = 1L, stream = 1L)
```

## Arguments

- design:

  A list or one-row data frame describing a design cell.

- replication:

  Positive replication number.

- base_seed:

  Base integer seed.

- stream:

  Optional independent stream number.

## Value

The documented eyeprocess object, data frame, plot, report path, or
adapter result.
