# Audit a placebo/pre-event window

Audit a placebo/pre-event window

## Usage

``` r
placebo_window_audit(data, time, value, window, expected = 0, by = NULL)
```

## Arguments

- data:

  Data frame.

- time:

  Time column.

- value:

  Value column.

- window:

  Two-element placebo window.

- expected:

  Optional expected mean, typically zero.

- by:

  Optional grouping columns.
