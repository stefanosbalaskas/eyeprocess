# Plot detected process change points

Plot detected process change points

## Usage

``` r
plot_process_changepoint(object, ...)
```

## Arguments

- object:

  An \`eye_irt_changepoints\`, \`eye_changepoint_rt_irt\`, or
  \`eye_changepoint_multimodal_irt\` object.

- ...:

  Graphical arguments.

## Value

An R object containing plot detected process change points. The concrete
class and structure follow the selected method, engine, or input object
and are preserved as documented by that workflow.
