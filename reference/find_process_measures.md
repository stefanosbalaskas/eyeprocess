# Find process measures by channel, level, status, or text

Find process measures by channel, level, status, or text

## Usage

``` r
find_process_measures(
  registry = process_measure_registry(),
  channel = NULL,
  level = NULL,
  status = NULL,
  query = NULL
)
```

## Arguments

- registry:

  Registry.

- channel:

  Optional channel filter.

- level:

  Optional level pattern.

- status:

  Optional status filter.

- query:

  Optional text query.
