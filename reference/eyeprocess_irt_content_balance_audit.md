# Audit content balance in an administered adaptive form

Audit content balance in an administered adaptive form

## Usage

``` r
eyeprocess_irt_content_balance_audit(administered, item_bank, target = NULL)
```

## Arguments

- administered:

  Identifiers or records for administered items.

- item_bank:

  Item bank or item-bank data frame.

- target:

  Target level, distribution, or criterion.
