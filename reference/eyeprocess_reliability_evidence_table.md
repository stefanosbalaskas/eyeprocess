# Build a paper-ready reliability table

Build a paper-ready reliability table

## Usage

``` r
eyeprocess_reliability_evidence_table(x, digits = 4L)
```

## Arguments

- x:

  Object to validate, summarize, verify, or otherwise process.

- digits:

  Number of decimal digits used for presentation.

## Value

An R object containing a paper-ready reliability table. The concrete
class and structure follow the selected method, engine, or input object
and are preserved as documented by that workflow.
