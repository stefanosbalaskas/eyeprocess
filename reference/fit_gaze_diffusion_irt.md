# Fit a gaze-informed diffusion/accumulation workflow

Fit a gaze-informed diffusion/accumulation workflow

## Usage

``` r
fit_gaze_diffusion_irt(x, spec = gaze_diffusion_spec(), ...)
```

## Arguments

- x:

  An \`eye_dataset\`.

- spec:

  Diffusion specification.

- ...:

  Passed to the selected engine.

## Value

An \`eye_gaze_diffusion_irt\` object.
