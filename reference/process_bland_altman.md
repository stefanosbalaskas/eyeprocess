# Bland-Altman repeatability summary for two sessions

Bland-Altman repeatability summary for two sessions

## Usage

``` r
process_bland_altman(data, person, session, measure, sessions = NULL)
```

## Arguments

- data:

  Long data.

- person:

  Participant column.

- session:

  Session column containing exactly two selected sessions.

- measure:

  Measure column.

- sessions:

  Optional two session labels.
