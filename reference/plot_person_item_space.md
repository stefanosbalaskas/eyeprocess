# Plot person/item latent-space coordinates

Plot person/item latent-space coordinates

## Usage

``` r
plot_person_item_space(object, dimensions = c(1L, 2L), labels = FALSE, ...)
```

## Arguments

- object:

  Fitted \`eye_latent_space_irt\` object.

- dimensions:

  Two coordinate dimensions to display.

- labels:

  Whether to add entity labels.

- ...:

  Graphical arguments.
