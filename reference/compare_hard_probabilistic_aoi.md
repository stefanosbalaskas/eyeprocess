# Compare hard and probabilistic AOI assignments

Compare hard and probabilistic AOI assignments

## Usage

``` r
compare_hard_probabilistic_aoi(
  data,
  aois,
  probabilistic,
  x = "gaze_x",
  y = "gaze_y"
)
```

## Arguments

- data:

  Gaze samples.

- aois:

  Rectangular AOIs.

- probabilistic:

  Probabilistic assignment object.

- x, y:

  Gaze-coordinate columns.
