# Audit reporting-guideline coverage

Audit reporting-guideline coverage

## Usage

``` r
reporting_guideline_audit(x, model = NULL, sensitivity = NULL)
```

## Arguments

- x:

  An \`eye_dataset\`.

- model:

  Optional \`eyeprocess_model\`.

- sensitivity:

  Optional \`eye_multiverse\` sensitivity result.

## Value

An \`eye_reporting_audit\` data frame.
