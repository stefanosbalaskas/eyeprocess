# Inject an additive device/site shift in a numeric feature

Inject an additive device/site shift in a numeric feature

## Usage

``` r
inject_device_shift(data, column, shift, rows = NULL)
```

## Arguments

- data:

  Data.

- column:

  Numeric column.

- shift:

  Additive shift.

- rows:

  Optional logical/index rows affected.

## Value

An R object containing inject an additive device/site shift in a numeric
feature. The concrete class and structure follow the selected method,
engine, or input object and are preserved as documented by that
workflow.
