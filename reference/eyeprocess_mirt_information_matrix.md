# Multidimensional 2PL item information matrix

Multidimensional 2PL item information matrix

## Usage

``` r
eyeprocess_mirt_information_matrix(
  theta,
  discrimination,
  difficulty = 0,
  D = 1
)
```

## Arguments

- theta:

  Latent-trait value or vector of latent-trait values.

- discrimination:

  Discrimination vector or matrix.

- difficulty:

  Item difficulty or location parameter.

- D:

  Logistic scaling constant.
