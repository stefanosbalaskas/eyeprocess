# Compare psychometric DIF effect sizes with process-channel contrasts

Compare psychometric DIF effect sizes with process-channel contrasts

## Usage

``` r
eyeprocess_irt_process_dif_concordance(
  dif,
  process,
  item_id = "item_id",
  dif_effect = "effect",
  process_effect = "effect"
)
```

## Arguments

- dif:

  Differential-item-functioning evidence or summary.

- process:

  Process-measure columns or process object.

- item_id:

  Item identifier or vector of item identifiers.

- dif_effect:

  DIF effect used for concordance.

- process_effect:

  Process-side item effect used for concordance.
