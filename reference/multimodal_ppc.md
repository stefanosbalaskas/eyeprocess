# Posterior predictive checks for multimodal development fits

Posterior predictive checks for multimodal development fits

## Usage

``` r
multimodal_ppc(object, variables = NULL)
```

## Arguments

- object:

  An \`eye_multimodal_irt_fit\`.

- variables:

  Optional generated-quantity variable names.

## Value

An \`eye_multimodal_ppc\`.
