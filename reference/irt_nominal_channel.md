# Nominal response/process channel

Nominal response/process channel

## Usage

``` r
irt_nominal_channel(
  choice = "response_option",
  categories = NULL,
  latent = "ability",
  options = list()
)
```

## Arguments

- choice:

  Observed nominal choice.

- categories:

  Nominal response categories.

- latent:

  Latent variable or latent-variable labels.

- options:

  Additional channel/model options.
