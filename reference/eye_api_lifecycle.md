# Normalize or create an API lifecycle registry

Normalize or create an API lifecycle registry

## Usage

``` r
eye_api_lifecycle(registry = NULL)
```

## Arguments

- registry:

  Optional data frame with at least \`name\` and \`status\`. \`NULL\`
  loads the packaged 0.9 lifecycle registry.

## Value

\`eye_api_lifecycle\` data frame.
