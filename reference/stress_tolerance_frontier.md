# Identify the empirical stress frontier for a metric

Identify the empirical stress frontier for a metric

## Usage

``` r
stress_tolerance_frontier(x, severity, metric, acceptable)
```

## Arguments

- x:

  Stress-test result.

- severity:

  Numeric corruption/severity column.

- metric:

  Metric column.

- acceptable:

  Function returning TRUE/FALSE for metric values.
