# Inject trial/row imbalance by dropping observations

Inject trial/row imbalance by dropping observations

## Usage

``` r
inject_trial_imbalance(data, proportion, seed = 1L)
```

## Arguments

- data:

  Data.

- proportion:

  Proportion dropped.

- seed:

  Seed.

## Value

A tabular R object containing inject trial/row imbalance by dropping
observations; rows represent analysis units and columns contain the
returned quantities.
