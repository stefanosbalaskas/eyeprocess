# Compare raw and confound-adjusted pupil values

Compare raw and confound-adjusted pupil values

## Usage

``` r
compare_raw_adjusted_pupil(x)
```

## Arguments

- x:

  Object to process, inspect, compare, or plot.

## Value

A data frame containing raw and confound-adjusted pupil values. Rows
represent the analysis units and columns contain the identifiers,
estimates, or diagnostics defined by the function.
