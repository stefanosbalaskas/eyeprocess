# Bind compatible process-window objects

Bind compatible process-window objects

## Usage

``` r
bind_process_windows(...)
```

## Arguments

- ...:

  Additional arguments passed to the underlying method or helper.

## Value

An object of class "eye_process_windows", stored as a named list, with
components "data", "spec", "source_n", "status". It contains bind
compatible process-window objects and associated metadata or diagnostics
needed to interpret the result.
