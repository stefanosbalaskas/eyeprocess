# Define a computational benchmark design

Define a computational benchmark design

## Usage

``` r
eye_benchmark_design(
  n_obs = c(10000, 1e+05, 1e+06),
  repetitions = 3L,
  label = "eyeprocess_scaling"
)
```

## Arguments

- n_obs:

  Observation counts.

- repetitions:

  Repetitions per size.

- label:

  Benchmark label.
