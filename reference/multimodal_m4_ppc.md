# Posterior predictive checks for M4 measurement and sequential behavior

Compares observed process summaries with posterior-replicated summaries
and reports replicated latent-state dynamics separately. Because states
are latent, inferred state labels are never treated as observed ground
truth.

## Usage

``` r
multimodal_m4_ppc(x)
```

## Arguments

- x:

  An M4 fit.

## Value

An \`eye_multimodal_m4_ppc\`.
