# Summarize extracted process windows

Summarize extracted process windows

## Usage

``` r
summarize_process_windows(x, by = NULL)
```

## Arguments

- x:

  \`eye_process_windows\` object.

- by:

  Optional grouping columns present in the extracted table.

## Value

An R object containing extracted process windows. The concrete class and
structure follow the selected method, engine, or input object and are
preserved as documented by that workflow.
