# Directional multidimensional 2PL information

Directional multidimensional 2PL information

## Usage

``` r
eyeprocess_mirt_directional_information(
  theta,
  discrimination,
  difficulty = 0,
  direction = NULL,
  D = 1
)
```

## Arguments

- theta:

  Latent-trait value or vector of latent-trait values.

- discrimination:

  Discrimination vector or matrix.

- difficulty:

  Item difficulty or location parameter.

- direction:

  Direction vector used to project multidimensional information.

- D:

  Logistic scaling constant.
