# Substantive-threshold stability across specifications

Substantive-threshold stability across specifications

## Usage

``` r
sensitivity_threshold_stability(
  x,
  effect = "effect",
  threshold = 0,
  direction = c("above", "below", "absolute")
)
```

## Arguments

- x:

  Sensitivity result.

- effect:

  Effect column.

- threshold:

  Threshold.

- direction:

  \`above\`, \`below\`, or \`absolute\`.
