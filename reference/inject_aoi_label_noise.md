# Inject AOI label noise

Inject AOI label noise

## Usage

``` r
inject_aoi_label_noise(data, aoi = "aoi", proportion, seed = 1L)
```

## Arguments

- data:

  Data.

- aoi:

  AOI label column.

- proportion:

  Proportion reassigned to another observed label.

- seed:

  Seed.

## Value

An R object containing inject AOI label noise. The concrete class and
structure follow the selected method, engine, or input object and are
preserved as documented by that workflow.
