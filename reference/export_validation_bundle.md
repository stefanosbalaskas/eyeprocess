# Export a validation evidence bundle

Export a validation evidence bundle

## Usage

``` r
export_validation_bundle(x, directory, overwrite = FALSE, include_rds = TRUE)
```

## Arguments

- x:

  Validation bundle.

- directory:

  Output directory.

- overwrite:

  Allow writing into a non-empty target directory.

- include_rds:

  Save full R objects as RDS.
