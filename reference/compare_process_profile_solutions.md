# Compare candidate process-profile solutions

Compare candidate process-profile solutions

## Usage

``` r
compare_process_profile_solutions(data, variables, k_values = 2:6, seed = 777)
```

## Arguments

- data:

  Person-level process data.

- variables:

  Variables used for profiling.

- k_values:

  Candidate numbers of profiles.

- seed:

  Seed.
