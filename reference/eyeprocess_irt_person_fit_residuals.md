# Compute person residual fit summaries

Compute person residual fit summaries

## Usage

``` r
eyeprocess_irt_person_fit_residuals(
  responses,
  probabilities,
  person_ids = rownames(responses)
)
```

## Arguments

- responses:

  Response matrix or response data.

- probabilities:

  Probability matrix or vector, with dimensions appropriate to the
  model.

- person_ids:

  Optional person identifiers.
