# Distance to nearest rectangular AOI boundary

Distance to nearest rectangular AOI boundary

## Usage

``` r
fixation_boundary_uncertainty(data, aois, x = "gaze_x", y = "gaze_y")
```

## Arguments

- data:

  Gaze samples.

- aois:

  Rectangular AOIs.

- x, y:

  Coordinates.

## Value

A tabular R object containing distance to nearest rectangular AOI
boundary; rows represent analysis units and columns contain the returned
quantities.
