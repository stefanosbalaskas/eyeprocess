# Mean-sigma IRT linking coefficients

Mean-sigma IRT linking coefficients

## Usage

``` r
eyeprocess_irt_mean_sigma_link(reference, focal, anchors = NULL)
```

## Arguments

- reference:

  Reference-form or reference-group item parameters.

- focal:

  Focal-form or focal-group item parameters.

- anchors:

  Anchor-item identifiers.
