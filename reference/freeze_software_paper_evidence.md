# Freeze software-paper evidence to an RDS with a hash

Freeze software-paper evidence to an RDS with a hash

## Usage

``` r
freeze_software_paper_evidence(x, path)
```

## Arguments

- x:

  Evidence bundle.

- path:

  Output path.

## Value

A data frame containing freeze software-paper evidence to an RDS with a
hash. Rows represent the analysis units and columns contain the
identifiers, estimates, or diagnostics defined by the function.
