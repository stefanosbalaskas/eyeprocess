# Audit item response-function shape departures

Audit item response-function shape departures

## Usage

``` r
audit_irf_shape(
  comparison,
  mean_absolute_threshold = 0.05,
  max_absolute_threshold = 0.15
)
```

## Arguments

- comparison:

  Value supplied to \`comparison\`; see Details for its model-specific
  role.

- mean_absolute_threshold:

  Threshold for mean absolute IRF departure.

- max_absolute_threshold:

  Threshold for maximum absolute IRF departure.
