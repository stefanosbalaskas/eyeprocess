# Create a gated persistence-augmented gaze-diffusion IRT interface

Create a gated persistence-augmented gaze-diffusion IRT interface

## Usage

``` r
fit_persistence_gaze_diffusion_irt(data, engine = NULL, ...)
```

## Arguments

- data:

  Response/RT/process data.

- engine:

  Optional externally validated estimator function.

- ...:

  Passed to \`engine\`.
