# 4PL item-response probability

4PL item-response probability

## Usage

``` r
eyeprocess_irt_4pl_probability(theta, a = 1, b = 0, c = 0, d = 1, D = 1)
```

## Arguments

- theta:

  Latent-trait value or vector of latent-trait values.

- a:

  Item discrimination parameter or vector.

- b:

  Item difficulty or location parameter or vector.

- c:

  Lower-asymptote parameter or vector.

- d:

  Upper-asymptote parameter or vector.

- D:

  Logistic scaling constant.
