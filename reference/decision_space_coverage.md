# Coverage of a declared decision space by evaluated specifications

Coverage of a declared decision space by evaluated specifications

## Usage

``` r
decision_space_coverage(grid, evaluated)
```

## Arguments

- grid:

  Sensitivity grid.

- evaluated:

  Sensitivity result or vector of evaluated specification IDs.

## Value

A data frame containing coverage of a declared decision space by
evaluated specifications. Rows represent the analysis units and columns
contain the identifiers, estimates, or diagnostics defined by the
function.
