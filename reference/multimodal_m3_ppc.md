# Posterior predictive checks for the M3 four-channel model

Extends the M2 W/L/M discrepancy family with a standardized pupil
residual discrepancy P. Tail flags are diagnostics, not construct
validation.

## Usage

``` r
multimodal_m3_ppc(x)
```

## Arguments

- x:

  An M3 fit.

## Value

An \`eye_multimodal_m3_ppc\`.
