# Compare two research decision manifests

Compare two research decision manifests

## Usage

``` r
compare_decision_manifests(old, new)
```

## Arguments

- old:

  Earlier manifest.

- new:

  Later manifest.

## Value

An object of class "eye_decision_manifest_diff", "data.frame", stored as
a data frame, containing two research decision manifests and associated
metadata needed to interpret the result.
