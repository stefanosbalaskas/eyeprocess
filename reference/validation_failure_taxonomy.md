# Classify common estimator failures without hiding the original message

Classify common estimator failures without hiding the original message

## Usage

``` r
validation_failure_taxonomy(x)
```

## Arguments

- x:

  Error/condition/message vector.

## Value

A data frame containing classify common estimator failures without
hiding the original message. Rows represent the analysis units and
columns contain the identifiers, estimates, or diagnostics defined by
the function.
