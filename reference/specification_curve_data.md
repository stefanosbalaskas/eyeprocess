# Prepare ordered specification-curve data

Prepare ordered specification-curve data

## Usage

``` r
specification_curve_data(x, effect = "effect", lower = NULL, upper = NULL)
```

## Arguments

- x:

  Sensitivity result.

- effect:

  Effect column.

- lower:

  Optional lower interval column.

- upper:

  Optional upper interval column.

## Value

A tabular R object containing ordered specification-curve data; rows
represent analysis units and columns contain the returned quantities.
