# Generalized partial-credit category probabilities

Generalized partial-credit category probabilities

## Usage

``` r
eyeprocess_irt_gpcm_probability(theta, a = 1, steps, D = 1)
```

## Arguments

- theta:

  Latent-trait value or vector of latent-trait values.

- a:

  Item discrimination parameter or vector.

- steps:

  Step parameters for a generalized partial-credit model.

- D:

  Logistic scaling constant.
