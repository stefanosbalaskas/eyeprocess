# Write a methodological software-paper scaffold

Write a methodological software-paper scaffold

## Usage

``` r
write_software_paper_scaffold(
  path,
  title = "eyeprocess: Reproducible Psychometric Process Modelling in R",
  author = "Stefanos Balaskas"
)
```

## Arguments

- path:

  Output R Markdown file.

- title:

  Paper title.

- author:

  Author string.

## Value

The normalized path.
