# Create an index over frozen validation evidence artifacts

Create an index over frozen validation evidence artifacts

## Usage

``` r
eyeprocess_validation_evidence_index(root, recursive = TRUE)
```

## Arguments

- root:

  Root directory for evidence indexing.

- recursive:

  Whether evidence files are indexed recursively.

## Value

A data frame containing an index over frozen validation evidence
artifacts. Rows represent the analysis units and columns contain the
identifiers, estimates, or diagnostics defined by the function.
