# Process-aware selection penalty without mental-state inference

Process-aware selection penalty without mental-state inference

## Usage

``` r
eyeprocess_irt_process_aware_selection_penalty(
  information,
  burden,
  burden_weight = 0,
  quality_risk = 0,
  quality_weight = 0
)
```

## Arguments

- information:

  Item or test information value or vector.

- burden:

  Item-level process burden or cost measure.

- burden_weight:

  Weight applied to the burden penalty.

- quality_risk:

  Item-level measurement-quality risk.

- quality_weight:

  Weight applied to the quality-risk penalty.
