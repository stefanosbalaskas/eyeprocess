# Compare recovery under reference and misspecified scenarios

Compare recovery under reference and misspecified scenarios

## Usage

``` r
eyeprocess_irt_misspecification_metrics(
  reference_summary,
  misspecified_summary
)
```

## Arguments

- reference_summary:

  Reference-model validation summary.

- misspecified_summary:

  Misspecified-model validation summary.

## Value

An R object containing recovery under reference and misspecified
scenarios. The concrete class and structure follow the selected method,
engine, or input object and are preserved as documented by that
workflow.
