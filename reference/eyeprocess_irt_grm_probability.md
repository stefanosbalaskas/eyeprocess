# Graded-response category probabilities

Graded-response category probabilities

## Usage

``` r
eyeprocess_irt_grm_probability(theta, a = 1, thresholds, D = 1)
```

## Arguments

- theta:

  Latent-trait value or vector of latent-trait values.

- a:

  Item discrimination parameter or vector.

- thresholds:

  Ordered response-category thresholds.

- D:

  Logistic scaling constant.
