# Pairwise temporal stability across sessions

Pairwise temporal stability across sessions

## Usage

``` r
process_temporal_stability(
  data,
  person,
  session,
  measure,
  method = c("pearson", "spearman")
)
```

## Arguments

- data:

  Long data.

- person, session, measure:

  Column names.

- method:

  Correlation method.
