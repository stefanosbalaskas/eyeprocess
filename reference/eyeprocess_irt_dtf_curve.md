# Differential test functioning effect curve

Differential test functioning effect curve

## Usage

``` r
eyeprocess_irt_dtf_curve(reference, focal, theta = seq(-4, 4, length.out = 81))
```

## Arguments

- reference:

  Reference-form or reference-group item parameters.

- focal:

  Focal-form or focal-group item parameters.

- theta:

  Latent-trait value or vector of latent-trait values.
