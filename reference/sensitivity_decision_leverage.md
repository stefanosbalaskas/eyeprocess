# Decision leverage of each analytical choice

Leverage is descriptive variation in mean effect across option levels;
it is not causal attribution of researcher decisions.

## Usage

``` r
sensitivity_decision_leverage(x, effect = "effect")
```

## Arguments

- x:

  Sensitivity result.

- effect:

  Effect column.

## Value

A tabular R object containing decision leverage of each analytical
choice; rows represent analysis units and columns contain the returned
quantities.
