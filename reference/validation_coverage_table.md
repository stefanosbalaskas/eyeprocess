# Interval-coverage table

Interval-coverage table

## Usage

``` r
validation_coverage_table(x, nominal = 0.95, by = NULL)
```

## Arguments

- x:

  Validation result.

- nominal:

  Nominal coverage used for deviation reporting.

- by:

  Optional grouping variables.

## Value

A tabular R object containing interval-coverage table; rows represent
analysis units and columns contain the returned quantities.
