# Process-measure lineage table

Process-measure lineage table

## Usage

``` r
process_measure_lineage(
  measure,
  inputs,
  transformations = character(),
  output_level = NA_character_
)
```

## Arguments

- measure:

  Measure name.

- inputs:

  Required input variable names.

- transformations:

  Ordered transformation labels.

- output_level:

  Output aggregation level.
