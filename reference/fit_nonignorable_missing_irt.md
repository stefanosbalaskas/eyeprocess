# Create a gated Bayesian nonignorable-missing IRT interface

Create a gated Bayesian nonignorable-missing IRT interface

## Usage

``` r
fit_nonignorable_missing_irt(data, engine = NULL, ...)
```

## Arguments

- data:

  Response/missingness data.

- engine:

  Optional externally validated Bayesian estimator.

- ...:

  Passed to \`engine\`.
