# Detect a response-process change point

Public roadmap alias for \`detect_irt_changepoints()\`.

## Usage

``` r
detect_process_changepoint(...)
```

## Arguments

- ...:

  Additional arguments passed to the selected model, engine, or method.

## Value

An R object containing a response-process change point. The concrete
class and structure follow the selected method, engine, or input object
and are preserved as documented by that workflow.
