# Posterior predictive checks for the M2 three-way model

Reproduces the channel-specific discrepancy logic used in the published
three-way framework: response W, response-time L, and fixation-count M
residual statistics, aggregated by item.

## Usage

``` r
multimodal_m2_ppc(x)
```

## Arguments

- x:

  An \`eye_multimodal_m2_fit\` with \`model == "M2"\`.

## Value

An \`eye_multimodal_m2_ppc\`.
