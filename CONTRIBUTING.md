# Contributing to eyeprocess

New vendor adapters must provide: a conservative detector, an importer that
creates canonical tables, explicit timestamp and coordinate semantics,
loss-aware retention of unknown fields, synthetic fixtures, and tests against
multiple real export versions where licensing permits.

Experimental models must include a declared estimand, assumptions, simulation
or parameter-recovery evidence, failure diagnostics, and responsible-use notes.
Do not label derived components as attention, effort, engagement, or cognitive
load without a defensible validation argument.
